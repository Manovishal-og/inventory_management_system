
# 📦 Inventory Management System (Flask)

This project is a web-based **Inventory Management System** built using the **Flask framework**.  
It helps businesses manage stock, suppliers, purchases, sales, and profit reports through an easy-to-use interface.

---

## 🚀 Features

✔ User authentication & login  
✔ Add, view, and manage stock items  
✔ Supplier management  
✔ Record purchases and sales  
✔ Track stock availability  
✔ Profit reporting system  
✔ Responsive UI with HTML templates and CSS  

---

## 🛠️ Tech Stack

- **Python (Flask Framework)**
- Jinja2 Templates
- HTML / CSS  
- SQLite / MySQL (based on configuration)

---

## 📂 Project Structure


app.py                 # Main application file
templates/             # HTML UI pages
static/style.css       # Styling


Key templates include:

- login.html
- main_menu.html
- inventory.html
- suppliers.html
- purchase_history.html
- sales_history.html
- profit_report.html
- add_purchase.html
- add_sale.html
- add_supplier.html

## 📌 Installation & Setup

### 1️⃣ Clone this repository

```bash
git clone https://github.com/YOUR_USERNAME/inventory_management_system.git
cd inventory_management_system
````

### 2️⃣ Create & activate virtual environment (recommended)

```bash
python3 -m venv venv
source venv/bin/activate   # Linux/macOS
venv\Scripts\activate      # Windows
```

### 3️⃣ Install dependencies

```bash
pip install flask
```

(If you have `requirements.txt`, use `pip install -r requirements.txt`)

---

## ▶️ Run the Application

```bash
python app.py
```

Then open your browser and visit:

```
http://127.0.0.1:5000/
```
